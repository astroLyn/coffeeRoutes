# Bitácora de UX - Fase 1: Landing Page

## Nicho Seleccionado
Mapa de Cafeterías Locales en Tijuana (Turismo/Gastronomía).

## Decisiones de Diseño (UX)
1. **Metáforas Visuales:**
   - **Paleta de Colores:** Se eligieron tonos cálidos (marrón tostado, beige crema, terracota) para evocar la experiencia sensorial del café (olor, sabor, calidez).
   - **Tipografía:** Se buscará una fuente Sans Serif limpia para modernidad, combinada quizás con una Serif en títulos para denotar la elegancia de lo "artesanal".

2. **Heurística de Nielsen: Correspondencia entre sistema y mundo real:**
   - En lugar de usar "pines" genéricos rojos, la interfaz preparará al usuario para buscar "tazas" o "granos".
   - El lenguaje del CTA no será "Buscar ubicación", sino "Encuentra tu Café", haciendo alusión a la experiencia, no a la coordenada.

3. **Propuesta de Valor en la Landing:**
   - El "Hero Section" debe mostrar inmediatamente una imagen que evoque una cafetería local de Tijuana (estilo industrial/hipster común en la zona) o un mapa estilizado.
   - El botón (CTA) debe ser el elemento con mayor contraste.
